## Generation Notes

### Veo 3.1 API Parameters
```python
# Per scene:
operation = client.models.generate_videos(
    model="veo-3.1-generate-preview",
    prompt=SCENE_PROMPT,
    # Up to 3 reference images per generation
    reference_images=[tiche_ref, salon_ref],
    config=genai.types.GenerateVideosConfig(
        aspect_ratio="16:9",  # landscape
        resolution="1080p",
        number_of_videos=1,  # generate 2-3 variations per scene
    )
)
```

### Recommended Generation Order
1. **Scenes 1, 9, 11** — Tiche in salon (highest quality reference, generate first)
2. **Scenes 3, 4, 5, 8** — App UI close-ups (simpler, phone-focused)
3. **Scenes 6, 12** — Hands/action shots
4. **Scenes 2, 7, 10, 13** — Supporting scenes
5. **Scenes 14, 15** — Product/brand shots (no reference needed)

### Post-Production
- Stitch 15 × 8-second clips together
- Add music bed (upbeat, professional, salon-appropriate)
- Color grade for consistency (warm, slightly saturated)
- Add text overlays for key features
- Brand watermark bottom-right

### Audio Options
- **Option A:** Use Tiche's voice from salon video for voiceover
- **Option B:** Generate AI voiceover via ElevenLabs or Gemini Audio
- **Option C:** Text overlays only + music (no voiceover)

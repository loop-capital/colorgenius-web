## Lessons Learned

### Git
- ALWAYS commit before making risky changes
- Use `git stash` before `git checkout`
- Never run `git checkout HEAD -- .` without stashing first

### Deployments
- Batch changes — don't deploy after every tiny edit
- Vercel free tier: 100 deploys/day
- Test build locally before deploying: `npx next build`

### Next.js App Router
- ALL buttons MUST have `type="button"` — without it, they default to `type="submit"` and clicks are swallowed during hydration
- `motion.button` and `motion.circle` with onClick are unreliable — use plain HTML buttons
- SVG `motion.circle` onClick doesn't fire in all browsers — use `<g>` wrapper or transparent overlay
- Framer-motion `whileHover`/`whileTap` on regular `<button>` elements breaks click handlers

### Component Safety
- HairSwatch and ColorCircle work because they have `type="button"` on internal elements
- GlassCard, StepTransition can interfere with click propagation
- Always check that wrapper components don't block pointer events

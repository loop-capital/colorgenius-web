# COLORgenius Pro Certification Course
## Free Online Course for Licensed Hair Colorists

---

## Course Overview

**Target Audience:** Licensed hair colorists, salon professionals, cosmetology students  
**Duration:** 6 modules, ~2 hours each (12 hours total)  
**Format:** Video lessons + interactive demos + quizzes + hands-on practice  
**Certification:** COLORgenius Pro Certified (digital badge + certificate)  
**Cost:** FREE  
**Platform:** ByondEdu integration + standalone at colorgenius.com/academy

---

## Learning Objectives

By the end of this course, students will:
- Understand how COLORgenius analyzes hair and creates formulations
- Know how to input accurate client hair data for best results
- Be able to interpret and adjust AI-generated formulas
- Understand the color science behind the platform
- Use advanced features (custom mixing, historical tracking, profit analysis)

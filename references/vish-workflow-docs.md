# Vish Tablet Mixing — Complete Workflow Reference

> Source: https://docs.getvish.com/docs/tablet-mixing/
> Saved: 2026-05-12

## Complete Flow

### 1. Add Service to Appointment
- Log into app
- Select client/appointment
- Select "Add Services"
- Find desired service → tap "Add to Appointment"

### 2. Add Bowl / Start Formula
- Press "+ Add Bowl"
- Select "Start New Formula" (from scratch)
- See list of salon's manufacturers
- Select manufacturer → view product categories
- Select products → tap "Add To Formula"
- Search by: search bar, drill through categories, or scroll list (numerical/alphabetical)

### 3. Developer Screen
- Choose desired developer
- Tap "Add To Formula"

### 4. Formula Builder Screen
- Pre-set how much product to mix per ingredient
- Choose developer ratio
- Option to "Add Products" or "Add Developers" if missed
- Tap "Mix Now" to start mixing
- Cost Summary at top turns RED if product allowance exceeded
- $ icon shows Service Summary (product cost, allowance, extra charges to pass to guest)

### 5. Actual Mixing Screen (Scale Integration)
- Drop/bowl visualization fills as products are weighed
- Each ingredient weighed sequentially
- Re-weigh available if overpour
- g/oz toggle available

### 6. Reweigh
- After formula applied to client, re-weigh container
- Calculates waste
- Vish learns and adapts over time
- Requires original bowl on scale, must "settle" for 1+ second

### 7. Done
- Options: Log out, Back to Appointment, Back to Schedule

## Formula Statuses
- **ACTIVE**: Created, currently dispensing/mixing
- **REWEIGHED**: Applied to customer, container reweighed, complete
- **DISCARDED**: Not applied to client, product discarded
- **CLOSED**: Applied to customer, no reweigh needed

## Service Summary
- $ icon on top right (white when OK, red when over allowance)
- Shows: product cost, product allowance, extra product charges
- Available during mixing at any time
- Number of bowls shown as icons

## Discontinued Products
- Marked with (!) icon on formula builder
- Options: manufacturer-suggested replacement, custom replacement, or continue mixing

## Unit Toggle (g/oz)
- Available in: Settings, Build Formula screen, Mixing screen
- Can set default preference
- Can mix units (oz for one ingredient, g for another)

# 2026-05-15 Daily Log

## Major Work: Formula Recommendation Engine Refinement

### Hair Characteristic Fields — Three Distinct Fields Implemented
- **Texture** (strand diameter): "fine", "medium", "coarse" — drives processing time (-15%/0/+15%) and product quantity (0.9x/1.0x/1.15x)
- **Hair Pattern** (strand shape): "straight", "wavy", "curly", "coily" — affects application technique
- **Density** (strands per sq inch): "thin", "medium", "thick" — logistics-only, affects product quantity NOT formula

### Safety Guardrails
- Hard stops block formula generation entirely (5+ level lift, 4+ lift on colored hair, PPD allergy, chemo, pregnancy+lightening, henna/metallic, severe damage)
- Returns `{ success: false, hardStops, alternatives }` early
- Multi-session pathway: max 3 levels per session, 4+ weeks between
- Warnings allow proceeding with caution

### Underlying Pigment Prediction
- `predictUnderlyingPigment(targetLevel)` returns pigment name, tone family, and warmth level

### Product Quantity Estimation
- `estimateProductQuantity(texture, density, serviceType)` returns total oz, section breakdown, application time estimate
- Base quantities by texture × length, modified by service type multiplier

### UI Changes
- Replaced single "Hair Type" selector with three: Texture, Hair Pattern, Density
- Type aliases added: `TextureType`, `HairPatternType`, `DensityType`
- State fields: `fd.texture`, `fd.hairPattern`, `fd.density`

### API Changes
- Route passes through all new fields, maps `hairPattern` to `hairType`
- Existing API contract preserved with defaults

### Deployed
- Multiple deploys to colorgenius.co
- All formulate-related TypeScript errors resolved

### Architecture Decision: Step Ordering
- Colorist workflow: Look at hair first (texture/pattern/density) → Determine current state (level + tone) → Decide target
- Step 2 reorder: Texture → Hair Pattern → Density → Current Level → Current Tone
- Step 3: Target Level → Target Tone

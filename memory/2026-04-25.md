## What Was Learned
- Vercel Serverless Functions run from `.next/server/` — relative paths from `process.cwd()` don't reach workspace root. Must use fallback mock data or absolute paths
- `output: 'export'` disables SSR — need to remove this for dynamic API routes to work properly at runtime (not just build time)
- Dark-mode CSS variable approach works great — shadcn/ui components inherit automatically once globals.css is correct

## Blockers
- `output: 'export'` in next.config.ts prevents true SSR — API routes work at build time but dynamic routes may be limited
- color-lines directory not accessible in Vercel runtime — fallback to mock data works but not ideal

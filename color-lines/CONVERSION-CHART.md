# ColorGenius Cross-Brand Conversion Chart

## How to Use This Chart
Cross-brand conversions are **approximate recommendations only**. Actual results vary based on:
- Natural hair porosity and texture
- Underlying pigment at the target level
- Developer volume used
- Processing time
- Previous color treatments

Always strand-test and adjust based on manufacturer guidelines.

## Special Notes

### Goldwell Unique Codes
- **K** = Copper (most brands use C)
- **O** = Orange (separate from copper — uncommon)
- **S** = Silver (cool ice/silver)
- Double letters = extra intensity (RR, VV, KK, AA)

### Pravana Dual Tone System
- First tone number = ~70% of tonal base
- Second tone number = ~30% of tonal base
- Example: 7.43 = Level 7, 70% Copper (.4) + 30% Gold (.3)

### L'Oréal vs Davines Similarities
- Both use decimal tone systems
- L'Oréal .8 = Pearl/Blue; Davines .8 = Mocha/Brown
- L'Oréal .2 = Green/Irisé; Davines .2 = Green/Iridescent
- Nearly identical at .0, .1, .3, .4, .5, .6, .7, .9

### Kenra Monochrome + Series
- Enhanced pigment for saturated gray coverage
- N+ = Natural Plus, NW+ = Natural Warm Plus
- May appear slightly darker than standard Kenra Color counterparts

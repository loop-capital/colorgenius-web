# ColorGenius — Correction Formulas

## When Color Goes Wrong: The Fix

---

## 1. Brassy / Orange Hair
**What happened:** Hair was lightened but didn't lift past the orange stage (levels 5-7). Most common correction request.

**The Rule:** Opposite on the color wheel neutralizes. Orange → Blue. Yellow → Violet.

### Level-Based Correction

| Current Level | Visible Problem | Neutralize With | Formula Example (Redken Shades EQ) |
|---------------|----------------|-----------------|-------------------------------------|
| 5-6 (Dark Orange) | Strong orange/brass | Blue-based ash | 5B + 5NA (1:1) + 10vol |
| 7 (Orange) | Copper orange | Blue-green ash | 7NB + 7NA (1:1) + 10vol |
| 8 (Yellow-Orange) | Brassy gold | Blue-violet | 8V + 8A (2:1) + 10vol |
| 9 (Yellow) | Pale yellow/warm | Violet | 9V + 9P (1:1) + 10vol |
| 10 (Pale Yellow) | Slight warmth | Violet-pearl | 10V + 10P (1:1) + 10vol |

### Wella Color Touch Formulas
| Problem | Formula | Developer |
|---------|---------|----------|
| Level 7 orange | 7/81 + 7/1 (1:1) | 1:1 + 4vol |
| Level 8 brassy | 8/81 + 8/1 (2:1) | 1:1 + 4vol |
| Level 9 yellow | 9/81 + 9/6 (1:1) | 1:1 + 4vol |
| Level 10 pale yellow | 10/6 + 10/1 (1:1) | 1:1 + 4vol |

### Pro Tips
- **Never use straight ash on levels 5-6** — green base will leave muddy/green cast. Use Natural Ash (NA/NB) instead
- **Blue additive** (like Ugly Duckling Ash Blue) is more effective at neutralizing orange than standard ash at lower levels
- **Process 10-15 min max** for toners — over-toning creates muddy results
- If brass is stubborn, use 20vol with toner for deeper penetration instead of 10vol

## 2. Green / Muddy Hair
**What happened:** Ash toner applied on hair that wasn't lifted enough. Green base of ash + orange underlying pigment = muddy green. OR swimming pool copper exposure.

**The Fix:** Add warmth back. Opposite of green is red.

### Formulas
| Current State | Fix Strategy | Formula Example |
|---------------|-------------|-----------------|
| Slight green cast | Add gold/warmth | Redken 8G + 8N (1:2) demi |
| Moderate green | Add copper warmth | 7C + 7N (1:3) demi |
| Heavy green/muddy | Red-based fill first | 6R + 6N (1:3) demi, then re-tone |
| Green from pool | Chelating treatment, then re-tone | Clarify + Malibu C + 9V toner |

### Pro Tips
- **Green is the hardest correction** — you cannot just add ash. You MUST reintroduce warmth
- If green is severe, deposit warm pigment first (copper or gold), THEN re-tone cooler
- For pool green: use a chelating treatment (Malibu C Un-Do-Goo) BEFORE re-toning
- Semi-permanent warm glosses are safer than permanent for this fix

## 3. Over-Toned / Purple / Blue Hair
**What happened:** Too much violet toner left on too long, or toner was too dark for the lightness level.

**The Fix:** Wash with clarifying shampoo to fade, then re-tone with correct level.

### Formulas
| Current State | Fix Strategy | Formula Example |
|---------------|-------------|-----------------|
| Slight purple tinge | Clarify + re-tone warmer | Clarify wash x2, then 9NB demi |
| Moderate purple | Clarify + gold gloss | Clarify + 9G + Clear (1:2) demi |
| Heavy purple/blue | Bleach wash + re-tone | Mild bleach wash, then 9P + 9V (2:1) |

### Pro Tips
- **Start with clarifying shampoo** — hot water + clarifying can remove 50-70% of demi toner
- Never re-tone over purple — it makes it worse
- If bleach wash is needed, use 10vol max to avoid further damage
- "Over-toned" almost always means the toner level was too low (dark), not the wrong tone

## 4. Uneven Color / Patchy
**What happened:** Uneven application, varying porosity, or overlapping color on previously colored hair.

**The Fix:** Create a uniform canvas first, then recolor.

### Strategy
1. **Assess porosity** — porous ends grab color darker, resistant roots grab lighter
2. **Fill porous ends** with a protein filler or clear gloss before recoloring
3. **Use lower developer volume** on porous areas (10vol) vs. higher on resistant (20vol)
4. **Apply to most resistant area first** (usually regrowth/natural hair)

### Formulas
| Problem | Fix Strategy |
|---------|-------------|
| Dark patchy ends | Lighten just the dark spots with 10vol + lightener, then re-tone overall |
| Light patchy spots | Fill with demi at the target level, then gloss overall |
| Hot roots (lighter at scalp) | Root smudge with demi-permanent at target level |
| Dark bands at line of demarcation | Break the base with 20vol lightener, then recolor |

## 5. Color Too Dark
**What happened:** Formula was too dark, or developer too low, or hair was more porous than expected.

**The Fix:** Gentle lift to remove some pigment.

### Formulas
| Problem | Fix Strategy |
|---------|-------------|
| 1 level too dark | Clarifying shampoo x3-5 washes fades demi-permanent |
| 2+ levels too dark | Bleach wash (lightener + 10vol shampoo) 5-10 min |
| Permanent too dark | Color remover (Effasol/Color Off) then recolor |
| Just applied (still wet) | Rinse immediately + clarifying wash before it processes |

### Pro Tips
- **Color remover > bleach** for "too dark" permanent color — less damaging
- Always re-tone AFTER color removal — underlying pigment will be exposed
- Hot water opens cuticle and helps fade unwanted deposit
- Dish soap (Dawn) mixed with shampoo is the strongest DIY clarifier

---

## 6. Color Too Light / Over-Lifted
**What happened:** Too high developer volume, or lightener left on too long, or hair was already light.

**The Fix:** Deposit color back to target level.

### Formulas
| Problem | Fix Strategy | Formula |
|---------|-------------|---------|
| 1 level too light | Deposit with demi | Target level N shade + 10vol |
| 2+ levels too light | Fill + deposit | Gold/copper filler, then target shade permanent |
| Over-bleached (mushy) | Protein first, then color | Olaplex/Bond builder, then demi at target level |

### Pro Tips
- **Never apply permanent color to over-bleached mushy hair** — use demi-permanent
- If hair stretches when wet, it needs bond builder BEFORE any color service
- Fill with the missing underlying pigment first (gold at 8, copper at 7, etc.)
- Over-lifted hair processes color 2-3x faster — reduce processing time by half

## 7. Red That Won't Stay / Fading Red
**What happened:** Red molecules are the smallest and escape the cuticle fastest.

**The Fix:** Fill with red first, use higher pigment load, and seal.

### Formulas
| Problem | Fix Strategy |
|---------|-------------|
| Red fading to orange | Pre-fill with red demi, then apply permanent red over |
| Red fading to pink/brown | Use double red (RR/5.66/6.66) + NN for gray coverage |
| Red going brassy | Add 1/4 oz red booster to any warm formula |
| Can't get red dark enough | Use level 3-4 red-violet (3RV, 4RV) instead of pure red |

### Pro Tips
- **Red is the #1 color that fades** — always formulate 1 level deeper than desired
- Fill with demi-permanent red BEFORE applying permanent red
- Cool water washing extends red color life significantly
- Red over previously blonde hair needs copper fill first or it goes pink

## Universal Correction Decision Tree

```
Is the problem too WARM? (brass/orange/yellow)
  → Neutralize with opposite on color wheel
  → Level 5-6: Blue-based
  → Level 7-8: Blue-violet based
  → Level 9-10: Violet-based

Is the problem too COOL? (green/blue/purple/muddy)
  → Add warmth back
  → Slight: Gold gloss
  → Moderate: Copper demi
  → Severe: Red fill first, then re-tone

Is the problem UNEVEN?
  → Create uniform canvas first
  → Fill dark spots or lighten light spots
  → Use different developer volumes per zone

Is the problem TOO DARK?
  → Fade: Clarifying shampoo / color remover
  → Never just apply lighter color over dark

Is the problem TOO LIGHT?
  → Deposit: Fill missing underlying pigment first
  → Then apply target shade
  → Use demi on damaged hair

Is the problem FADING?
  → Pre-fill with the missing pigment family
  → Formulate deeper than target
  → Seal with acid gloss after processing
```

# Matrix — SoColor, Color Sync, Light Master

## Brand Overview
Matrix (L'Oréal Professional) offers several color lines:
- **SoColor**: Permanent color with built-in care
- **Color Sync** (now Super Sync): Demi-permanent alkaline color for toning and glossing
- **Light Master**: Lightening and blonding system

## Matrix SoColor (Permanent)

### Shade System
- Level: 1-11 (1=darkest black, 11=lightest toner level)
- Tone: Letter-based system indicating undertones
- Format: Level + Tone Letter(s) (e.g., 5A = level 5 with ash tone)

### Tone Letter Meanings
- **N**: Neutral (natural base)
- **A**: Ash (cool, blue-based)
- **AV**: Ash Violet (cool, blue-violet based)
- **AA**: Ash Ash (double ash, intense cool)
- **G**: Gold (warm, yellow-based)
- **C**: Copper (warm, orange-based)
- **CG**: Copper Gold (warm, orange-yellow)
- **R**: Red (warm, red-based)
- **RB**: Red Brown (warm red with brown base)
- **RC**: Red Copper (warm, red-orange)
- **RV**: Red Violet (warm-cool, red-violet)
- **M**: Mocha (warm-cool, brown with red/gold)
- **MM**: Mocha Mocha (double mocha, intense warm brown)
- **MG**: Mocha Gold (warm brown with gold)
- **V**: Violet (cool, violet-based)
- **P**: Pearl (cool, pearlescent)
- **B**: Beige (neutral-warm, muted gold)
- **BR**: Brown Red (warm, brown with red)
- **BC**: Blonde Copper (warm blonde with copper)
- **W**: Warm (warm base)
- **NW**: Neutral Warm (slightly warm neutral)
- **WN**: Warm Neutral (slightly warm neutral)
- **NA**: Neutral Ash (cool neutral with ash)
- **NV**: Neutral Violet (cool neutral with violet)
- **T**: Titanium (cool, smoky)

### Key Characteristics
- Permanent color with Cera-Oil technology for built-in conditioning
- Up to 100% gray coverage
- Up to 5 levels of lift
- Mixing ratio: 1:1 with Matrix Cream Developer
- Processing time: 30-40 minutes
- Pre-bonded formula available (SoColor Bonded)

### Matrix Cream Developer (Volumes)
- 10 vol (3%): Deposit only, no lift
- 20 vol (6%): Standard lift (1-2 levels)
- 30 vol (9%): High lift (2-3 levels)
- 40 vol (12%): Maximum lift (3-5 levels)

### Processing Times
- Gray coverage: 35-45 minutes
- Standard processing: 30-40 minutes
- Maximum lift: 40-45 minutes

## Matrix Color Sync / Super Sync (Demi-Permanent)

### Shade System
- Same letter-based tone system as SoColor
- Level: 1-11 (11 = specialized toner level)
- Pre-bonded, no-ammonia alkaline demi-permanent

### Key Characteristics
- Demi-permanent alkaline glossing color
- No ammonia formula
- Lasts up to 24-28 shampoos
- Gray blending up to 50%
- Mixing ratio: 1:1 with Matrix Cream Developer (10 vol)
- Processing time: 10-20 minutes
- Can lift up to 2 levels lighter than natural base
- Level 11 Toners: Lightest level in Color Sync portfolio
